# Week 10 — Database Testing and System Integration

## Objective
The objective of this week was to review the database-related requirements and understand how database operations support backend APIs and frontend functionality.

## Work Completed
- Reviewed the examination data used by the backend.
- Studied how examination records were retrieved and managed through API endpoints.
- Reviewed the role of SQLite in local database management.
- Examined the database requirements for administrative examination operations.
- Considered how database records should be reflected in the frontend.
- Reviewed possible data consistency issues during system integration.

## Technical Work
The activities focused on:
- SQLite database concepts.
- Examination record management.
- Database retrieval operations.
- Data consistency.
- Backend and database interaction.
- Integration testing requirements.

## Learning and Understanding
I learned how the database acts as the storage layer of an application and how backend APIs communicate with it. I also understood that successful frontend integration depends on correct data retrieval and communication between application layers.

## Outcome
Database and system integration requirements were reviewed. Further verification of database operations and complete integration was still required.
