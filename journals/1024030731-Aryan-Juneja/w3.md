# Week 3 — Examination Database Tables and Search Queries

## Objective

The objective of Week 3 was to create the initial database structure for storing examination information and prepare the database for search operations.

## Work Completed

During this week, I worked on the examination-related database structure.

The examination table and its important attributes were planned according to the requirements of GovExam Alert. The database structure was designed to store information such as examination name, organization, important dates and deadlines.

The database was also prepared to support search and filtering operations that will be used by the backend.

## Technical Work

- Designed the examination database table.
- Identified important examination attributes.
- Created the initial examination data structure.
- Planned queries for retrieving examination information.
- Studied database requirements for search and filtering.
- Prepared the database structure for backend integration.

## Project Understanding

The examination table will store the core information displayed to users through the GovExam Alert application.

The database will later receive requests from the backend and return examination information required by the frontend.

## GitHub Work

The Week 3 database structure and query planning were documented and maintained in the team's GitHub repository.

## Outcome

The initial examination database structure was established and prepared for storing exam data and supporting search operations.
