# Week 5 — User Database and Role Management

## Objective

The objective of Week 5 was to plan the database structure required for storing user account information and supporting role-based access in GovExam Alert.

## Work Completed

During this week, I studied the data requirements for user registration, login and account management.

The user data structure was planned to store the information required by the application. Requirements for distinguishing regular users from administrators were also considered.

The database design was planned to support authentication and authorization features while maintaining data consistency.

## Technical Work

* Identified the attributes required for user records.
* Planned the user database table.
* Identified the data requirements for user roles.
* Studied relationships between user records and saved examinations.
* Considered primary keys and constraints for user data.
* Planned database support for authentication and account management.

## Project Understanding

The user database will maintain account-related information required by GovExam Alert. Role information will help the application distinguish regular users from administrators and support appropriate access controls through the backend.

Sensitive authentication information must be stored and managed securely.

## GitHub Work

The Week 5 database planning and schema-related work was documented as part of the team's ongoing development process in GitHub.

## Outcome

The initial requirements for user records and role management were identified, providing a foundation for integrating user accounts with the backend.
