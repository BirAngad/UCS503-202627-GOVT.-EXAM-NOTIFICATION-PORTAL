# Week 2 — Database Schema Planning and Exam Data Design

## Objective

The objective of Week 2 was to plan the database structure required for storing government examination information and other application data.

## Work Completed

During this week, I studied the data requirements of the GovExam Alert application and planned the initial database schema.

The main entities required by the application were identified, including examinations, users and information related to important examination dates.

The relationships between the entities were also considered so that the database can support the application's functionality.

## Technical Work

- Reviewed the database requirements of the project.
- Identified the main entities required by the application.
- Planned the initial examination data structure.
- Identified important attributes related to government examinations.
- Studied relationships between the major database entities.
- Planned the database structure for future backend integration.

## Project Understanding

The database will store the core information required by GovExam Alert.

The examination data will include important information such as examination name, organization, dates, deadlines and other relevant details. The database will later be connected with the backend services.

## GitHub Work

The initial database planning and schema design were documented as part of the Week 2 project development work in the team's GitHub repository.

## Outcome

The main database entities and examination data requirements were identified, providing a foundation for creating the database schema and integrating it with the backend.
