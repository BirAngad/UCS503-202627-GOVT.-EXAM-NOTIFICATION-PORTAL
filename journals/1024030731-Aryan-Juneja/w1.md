# Week 1 — Database Project Understanding and Planning

## Objective

The objective of Week 1 was to understand the database requirements of
the GovExam Alert project and establish the initial database design
approach.

## Work Completed

During this week, I studied the project requirements and identified the
information that needs to be stored by the application.

The database will support the backend by storing the information
required for government exam notifications and other application
entities that will be introduced during subsequent development stages.

I reviewed the notification-related information described in the
project requirements, including details such as title, organization,
category, application deadline, examination date and official source
link.

## Technical Work

- Studied the database requirements of the project.
- Identified the main information required for exam notifications.
- Reviewed the fields required for notification records.
- Planned the initial database structure.
- Identified the database responsibilities within the three-tier
  architecture.

## Project Understanding

The database will act as the persistent storage layer of GovExam Alert.
The backend will communicate with the database to store and retrieve
application data.

Additional database entities and relationships will be introduced as
the corresponding project functionality is developed in later weeks.

## GitHub Work

The database work was planned as a separate responsibility within the
team repository. Database changes will be committed incrementally as
the project develops.

## Outcome

At the end of Week 1, I developed an understanding of the database
requirements and established the foundation for implementing the
database layer in the upcoming development weeks.
