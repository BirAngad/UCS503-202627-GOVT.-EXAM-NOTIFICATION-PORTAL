# Week 5 — Authentication and Authorization

## Objective

The objective of Week 5 was to plan and develop the backend functionality required for user authentication and authorization in GovExam Alert.

## Work Completed

During this week, I studied the backend requirements for managing user accounts and controlling access to application features.

The authentication flow was planned to verify user credentials, while authorization requirements were considered for controlling access to user-specific and administrative operations.

The backend structure was organized to support secure communication between the frontend and authentication services.

## Technical Work

- Identified the backend requirements for user authentication.
- Planned the registration and login API endpoints.
- Studied the process of verifying user credentials.
- Identified authorization requirements for different user roles.
- Planned authentication error handling.
- Reviewed the integration flow between frontend authentication forms and backend APIs.

## Project Understanding

Authentication verifies the identity of users, while authorization determines which application features they can access.

These functions will help GovExam Alert manage user accounts and protect restricted operations, including administrative functionality.

## GitHub Work

The Week 5 backend planning and development work was documented as part of the team's ongoing project work in GitHub.

## Outcome

The basic requirements for authentication and authorization were identified, providing a foundation for implementing account management and access control.
