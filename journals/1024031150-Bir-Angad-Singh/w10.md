# Week 10 — Backend Testing and Frontend Integration

## Objective
The objective of this week was to test the backend APIs and work towards integrating backend services with the frontend application.

## Work Completed
- Reviewed the backend server configuration.
- Tested examination-related API endpoints using Thunder Client.
- Checked the GET endpoint for retrieving examination records.
- Tested administrative API operations for adding and managing examinations.
- Reviewed API responses and HTTP status codes.
- Investigated communication issues between the frontend and backend.
- Identified the need to verify API URLs, server availability, and CORS configuration.

## Technical Work
The testing activities included:
- GET `/api/exams`
- GET `/api/exams/:id`
- POST `/api/admin/exams`
- Testing API request and response structures.
- Checking successful and unsuccessful HTTP responses.
- Reviewing frontend-backend communication.

## Learning and Understanding
I learned how to test REST APIs using Thunder Client and how different HTTP methods are used for retrieving and managing examination records. I also understood that successful API testing does not automatically guarantee successful frontend integration.

## Outcome
Backend API testing was carried out, and administrative exam creation was successfully tested. However, frontend examination fetching continued to show a "Failed to fetch" error, so complete integration remained unresolved.
