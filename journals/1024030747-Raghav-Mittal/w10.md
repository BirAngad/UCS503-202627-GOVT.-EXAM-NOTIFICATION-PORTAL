# Week 10 — Frontend Integration and Testing

## Objective
The objective of this week was to work towards connecting the frontend application with the backend services and test the major frontend functionalities.

## Work Completed
- Reviewed the frontend API integration requirements.
- Worked on checking how examination data should be retrieved from the backend.
- Reviewed the frontend exam-listing and dashboard data flow.
- Tested the examination-fetching functionality.
- Identified an issue where the frontend displayed a "Failed to fetch" message instead of examination records.
- Reviewed the need to verify the backend service, API endpoint, and frontend-backend connection.

## Technical Work
The integration and testing activities focused on:
- Frontend API requests.
- Examination data retrieval.
- Loading and error states.
- Empty examination-list handling.
- Frontend-backend communication.
- Identifying possible API URL and CORS configuration issues.

## Learning and Understanding
I learned that frontend components require successful communication with backend APIs to display dynamic data. I also understood the importance of testing API requests and handling network errors properly.

## Outcome
Frontend integration and testing activities were carried out, but complete and reliable examination-data fetching was not achieved. The "Failed to fetch" issue remained unresolved and required further debugging.
